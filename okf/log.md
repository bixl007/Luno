# Luno Update Log

## 2026-11-03
* **Update**: Fixed "list the upcoming Indian cricket matches" failing with "I couldn't find dates": search now opens the best two result pages and adds their relevant lines (table rows, dated lines) to what the model reads, and the prompt says to list only events after today. See [web search](/ai/web-search.md).
* **Update**: Stopped the model guessing on live questions. Search now asks DuckDuckGo, Bing, Google News and Wikipedia at once and merges tagged results (Vercel's logs showed DuckDuckGo blocked and Bing weak), the system prompt forbids stating a current fact the results do not contain, and time and weather questions use a new live [place_conditions tool](/ai/place-conditions.md) (Open-Meteo) instead of search. See [web search](/ai/web-search.md).
* **Update**: Web search failed on the deployed site (luno.xyrix.fun) with "I couldn't check live information", most likely because DuckDuckGo's page is blocked from hosting addresses. Added Bing's RSS feed as a second keyless source (with a relevance filter, because Bing sometimes returns unrelated pages), so search is DuckDuckGo, then Bing, then Gemini grounding. No search key is needed. Not confirmed on the deployed site, see [web search](/ai/web-search.md).
* **Update**: Fixed the screen flickering while a reply streams: text updates are batched to every 80 ms, earlier messages no longer re-render, and the auto-scroll is instant while streaming and only follows the reader if they are at the bottom (a smooth scroll restarted on every word). See [chat interface](/ui/chat-ui.md).
* **Update**: PDF export now prints the rendered message through the browser's print dialog ("Save as PDF") instead of drawing plain text with `jspdf`, which broke on tables, code, long lines and non-Latin text. Checked by printing a sample with headings, a table, code, Hindi, Japanese and emoji to a real PDF in headless Chrome. `jspdf` is no longer imported anywhere.
* **Update**: Fixed web search failing. Free Gemini keys no longer get Google Search grounding (the 2.5 models answer `404`, the 3.x models `429`), so search now asks DuckDuckGo's results page first and keeps Gemini grounding as the fallback, see [web search](/ai/web-search.md).
* **Update**: After a reply the routes now save together (assistant message and chat update in parallel) and `POST /api/chat` builds its `done` payload from what it saved instead of reading the chat back. The database measured about 275 ms per round trip (2.8 s for the first connection), so the chat route's four sequential saves (about 1.1 s) became one wait.
* **Update**: Auto now tries a configured Groq or OpenRouter model first and falls back to Gemini (`AUTO_PREFER_GEMINI=1` reverses it), because the free Gemini models were slow or hung (3 to 40 s to a first word, measured). A real Auto reply started in 199 ms. Groq's default model changed from the retired `llama-4-scout` (which returned `404`) to `qwen/qwen3.8-27b`, see [models and files](/ai/models-and-files.md).
* **Update**: Rebuilt the settings dialog layout with a fixed height and a three-row grid (pinned header and footer, scrolling middle), and re-seated Chopper in the landing preview.
* **Update**: A reply that times out on every model now says so and suggests picking another model, instead of a generic error. Replies with attached files wait 35 s (not 15 s) for the model and hedge after 10 s, see [limits and quotas](/operations/limits-and-quotas.md). Triggered by all three Gemini models timing out at 15 s while the network to Google was fine (0.15 s to first byte); the root cause was not identified.
* **Creation**: Added an optional OpenRouter vision model to the model picker next to Groq, with configurable model lists (`*_MODELS`) and one shared transport (`src/lib/ai/compat.ts`); Mistral was left out because it is paid, see [models and files](/ai/models-and-files.md).
* **Update**: Chopper now says tech and nature facts, One Piece facts and One Piece jokes as well, see [personalisation](/ui/personalisation.md).
* **Creation**: File and photo upload (images, PDFs, text), a model picker and an optional free Groq vision model (`GROQ_API_KEY`), see [models and files](/ai/models-and-files.md). Schema: `User.preferences` and `Message.attachments` (migration `20261103210000_add_preferences_and_attachments`).
* **Creation**: Profile and AI personalisation (nickname, occupation, bio, response style, custom instructions, accent colour) through [/api/preferences](/api/preferences.md), and Chopper, the companion on the message box, see [personalisation](/ui/personalisation.md).
* **Update**: Fixed noisy read-aloud: speech is now cleaned of markup, split into sentences, spoken at normal speed with the best available voice, and the voice can be chosen. See [personalisation](/ui/personalisation.md).
* **Update**: Faster replies: the user message and `luno-ai` upsert are saved while the model answers, not before, and the default hedge delay dropped from 4 s to 2.5 s. Not measured against the live API.
* **Update**: `GET /api/message` and `POST /api/message` now check that the chat belongs to the signed-in user (they did not before).
* **Update**: Landing page redesigned: aurora hero, animated product preview, bento features, how it works, see [landing page](/ui/landing-page.md).
* **Update**: Redesigned the whole interface with one [design system](/ui/design-system.md): light, dark and system themes, new landing page, themed sign-in and sign-up, a rebuilt [chat interface](/ui/chat-ui.md) (persistent sidebar, delete confirmation, loading and empty states, a context panel that lists real sources) and 404, error and loading screens. Removed the unused decorative components and demos, and the dead `tailwind.config.js`. The Context panel's placeholder Memory, Tone and Model controls are gone because they did nothing.
* **Update**: The creator's website link is now https://xyrix.fun/ (system prompt and the two fallback replies).
* **Update**: Cut reply latency from 17 s (36 s with search) to roughly 3 to 7 s when the newest model is slow, with [hedged requests and model health memory](/ai/failover.md). Measured live: `gemini-3.8-flash` answers `503` or hangs, `gemini-3.6-flash` takes 2 to 16 s, the lite models answer in about 1 s.
* **Update**: Found the free tier allows about 20 requests a day per model (Google's `429` body). Daily-quota models are now skipped for an hour, `gemini-2.5-flash-lite` left the chat chain to protect search, and [limits and quotas](/operations/limits-and-quotas.md) was corrected.
* **Update**: Fixed web search failing with `404` on `gemini-2.5-flash` ("no longer available to new users"). Search now runs on `gemini-2.5-flash-lite` and fails over across a model chain; chat and search both treat `404` as failover; the chat fallback chain drops `gemini-2.5-flash`. The idle timeout dropped from 25 to 15 seconds. See [web search](/ai/web-search.md) and [chat model](/ai/chat-model.md).
* **Update**: Build checks now write to `.next-check` (`npm run build:check`, used by the pre-push hook) so they no longer overwrite a running dev server's `.next` folder, which had made pages lose their CSS. See [development](/operations/development.md).
